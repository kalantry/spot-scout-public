SpotScout is a mobile application that coordinates street parking handoffs by matching departing drivers with incoming commuters in high-density urban areas.

## Features

* **Scout Mode (Departing Drivers):** Mark an active street parking spot, set an estimated departure time, and earn reward points upon a completed handoff.
* **Hunter Mode (Arriving Drivers):** Locate nearby departing spots on a live map and reserve them using points or a flat fee.
* **10-Minute Hold Window:** A synchronized arrival countdown routes Hunters to the spot before the Scout exits to prevent spot squatting.
* **Reward System:** Earned points can be redeemed for local merchant vouchers or parking credits.
* **Location Verification:** Background GPS verification ensures Scouts are physically present at the reported spot.
